- [x] `stats` enable / edit — новая типизированная модель `StatsSettings` (`src/xray/config/stats_settings.rs`). Документация `StatsObject` прямо говорит: «В настоящее время для статистики не требуется никаких параметров» — секция официально пуста, поэтому «edit» здесь буквально сводится к «enable»: единственное значимое состояние — присутствие ключа `stats` в конфиге (`{"stats":{}}` включает модуль сбора статистики, отсутствие ключа выключает; фактический сбор данных управляется через `policy`/`api`/`metrics`, уже проверяется отдельными read-only wiring-предупреждениями, Roadmap §2.5:106, не тронуты).
